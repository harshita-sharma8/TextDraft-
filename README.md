# TextDraft- 📃
It is a simple, fast and lightweight plain-text editor designed for quick note-taking , drafting and managing ".txt" files without bloated formally.

## Features
**File Management:** It has a menu bar where file option contains create file, open file, save file in your local computer.

**Text Editor UI** The UI of TextDraft is simple, clean which make it lightweight

## Technology Used
It is purely made in Python module called Tkinter
